# 12-Factor App Notes

This repository contains structured notes on the **12-Factor App** methodology, based on the principles outlined at [12factor.net](https://12factor.net/). Each factor is documented with explanations, examples, and best practices for building scalable, maintainable, and cloud-native applications.

## What is the 12-Factor App?
The **12-Factor App** is a set of best practices for building modern, scalable web applications. It provides guidelines for software development that ensure applications are portable, resilient, and efficient in cloud environments.

## Repository Structure
The repository is organized into the following sections, each corresponding to one of the 12 factors:

```
12-factor-app-notes/
│── README.md  # Overview of the repository
│── 01-codebase/  # Factor 1: Codebase
│── 02-dependencies/  # Factor 2: Dependencies
│── 03-config/  # Factor 3: Config
│── 04-backing-services/  # Factor 4: Backing Services
│── 05-build-release-run/  # Factor 5: Build, Release, Run
│── 06-processes/  # Factor 6: Processes
│── 07-port-binding/  # Factor 7: Port Binding
│── 08-concurrency/  # Factor 8: Concurrency
│── 09-disposability/  # Factor 9: Disposability
│── 10-dev-prod-parity/  # Factor 10: Dev/Prod Parity
│── 11-logs/  # Factor 11: Logs
│── 12-admin-processes/  # Factor 12: Admin Processes
```

Each section will contain:
- **Summary:** A high-level explanation of the factor.
- **Details:** In-depth notes, examples, and best practices.
- **Code Snippets:** Where applicable, practical code examples.
- **Resources:** Links to additional readings or tools.

## Getting Started
To use this repository for learning or reference:
1. Clone the repo:  
   ```sh
   git clone https://github.com/henry-gay/12-factor-app-notes.git
   ```
2. Navigate to the desired factor folder and explore the notes.
